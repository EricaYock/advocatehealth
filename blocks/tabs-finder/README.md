# tabs-finder

Custom **tabs** block. Purpose: Tabbed finder band (e.g. Find a doctor / Find a location) with an authorable panel per tab.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one row per tab: cell 1 = tab label, cell 2 = panel content (text and a link to the finder app, e.g. /doctors or /locations).

## Supported variations

No variations.

N/A (Document Authoring project)
