# carousel-hero

Custom **carousel** block. Purpose: Full-bleed rotating hero; each slide has a background photo with heading, short text and a CTA overlaid.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one row per slide: cell 1 = background image (optional), cell 2 = heading (H1 on the first slide, H2 on the rest), paragraph, CTA link.
