# carousel-callout

Custom **carousel** block. Purpose: Rotating text-only callouts: heading, paragraph and a CTA per slide.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 or 2 columns, one row per slide: content cell = heading, paragraph, CTA link (an optional image cell is supported).

## Supported variations

No variations.
