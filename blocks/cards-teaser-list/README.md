# cards-teaser-list

Custom **cards** block. Purpose: Vertical list of article teasers: image, linked title, optional date and excerpt.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one row per teaser: cell 1 = image, cell 2 = linked title (paragraph link or heading), optional date paragraph, excerpt paragraph.
