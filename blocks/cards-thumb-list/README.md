# cards-thumb-list

Custom **cards** block. Purpose: Compact list of recent posts with small square thumbnails.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 columns, one row per post: cell 1 = thumbnail image, cell 2 = linked title, optional date paragraph.
